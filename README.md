# El Salvador Trip Guide

Bilingual interactive travel guide and map for international visitors to El Salvador.

## MVP features

- Interactive map with clickable place information
- English and Spanish interface
- Search, category and department filters
- Want-to-visit and visited checkmarks
- Bus, car-rental and eSIM discovery sections
- Responsive mobile and desktop design

## Deploy

Import this repository into Vercel. This initial version is a static site and requires no build command.
